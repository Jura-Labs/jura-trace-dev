ABOUT THIS FILE
--------------------------------------------------------------------------------

Jura Trace bundles open source software from four layers (Rust core, SvelteKit
frontend, Python ML sidecar, and ML model weights). The licences of those
components require us to reproduce their copyright and licence notices in this
distribution. This file does that.

Scope: only components that are actually shipped inside the installer are listed.
Build-time-only tooling (test frameworks, bundlers, linters) and ML libraries
explicitly excluded from the frozen sidecar binary (torch, torchvision,
open_clip runtime, timm, transformers, faster-whisper, ctranslate2,
invisible-watermark) are NOT distributed and are therefore not reproduced here.

Authoritative artefact: the per-component inventory below is a curated summary.
The exhaustive, per-package licence texts with exact copyright holders are
generated mechanically at release time by `scripts/generate-licenses.sh`
(cargo-about for Rust, license-checker for npm production deps, pip-licenses for
the frozen Python set) and appended under the MACHINE-GENERATED APPENDIX marker
at the end of this file. Where this summary and the generated appendix differ,
the generated appendix governs.

Last curated: 2026-05-26 against jura-trace 0.9.0.

================================================================================
4. ML MODELS AND DATA
================================================================================

  CLIP ViT-B/32 (ONNX)
    Architecture and tokeniser from OpenAI CLIP / OpenCLIP (open_clip), MIT
    licensed. Pretrained checkpoint: laion2b_s34b_b79k. Credit: LAION for the
    LAION-2B pretraining dataset and the OpenCLIP authors (Ilharco, Wortsman,
    Wightman, Gordon, Carlini, et al.).

  BPE vocabulary  (bpe_simple_vocab_16e6.txt.gz)
    MIT — OpenAI / OpenCLIP. The attribution header is preserved in
    sidecar/app/services/clip_tokenizer.py.

  UnivFD zero-shot AI-image detection method
    Linear probe on CLIP features per Ojha, Li & Lee, "Towards Universal Fake
    Image Detectors that Generalize Across Generative Models" (CVPR 2023). Cited
    in the in-app Model Cards.

  GBM deepfake classifier and the UnivFD probe weights
    First-party artefacts trained by Jura Labs CIC and distributed under
    AGPL-3.0-or-later alongside this application. Provenance and performance are
    documented in the in-app Model Cards.
