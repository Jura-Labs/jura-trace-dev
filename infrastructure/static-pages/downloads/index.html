Verify before installing. Jura Trace publishes SHA-256 sums and minisign signatures for every release. The desktop app's auto-updater verifies signatures before applying any update, but for the initial download we recommend confirming the SHA-256 against the published release notes. Step-by-step verification commands are in the verify-downloads guide.
